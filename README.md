# One Piece Wiki Project

Submitted to: Sir Amiel  
Subject: Web Development  

## About the Project

Hello Sir Amiel! This is our Web Development project, basically a One Piece Wiki website that we built using vanilla HTML and CSS.

The whole concept ani is to provide a clean and organized fan wiki about One Piece. Naa diri ang overview of the Great Pirate Era, the 4 Acts storyline synopsis, canon world systems like Haki and Devil Fruits, and ang profile pages of the Straw Hat crew. Aside from the 10 active members from Luffy down to Jinbe, gi-apil na pud namo ang duha ka legendary ships nila which are the Going Merry and Thousand Sunny, complete with their own pages, specs, history, and pictures.

We made sure nga responsive and limpyo ang styling sa site para structured and sayon ra i-browse.

## What We Made

- Main Landing Page: Contains the series overview, quick facts, 4 Acts synopsis, canon systems lore, and poster cards linking to each crew member and ship.
- Straw Hat Member Pages: Dedicated profile pages for each crew member showing their personal info, background, and personal goals.
- Ship Profile Pages: Dedicated pages for both Going Merry and Thousand Sunny containing their ship details, history, and gallery.
- Custom CSS Styling: Custom layouts and responsive cards para consistent and hapsay tan-awon across different screen sizes.
